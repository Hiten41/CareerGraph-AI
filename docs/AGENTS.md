# Agent and memory
The OpenAI-compatible chat completions client exposes eleven typed tools for profiles, search, filters, details, explanation, comparison, saved jobs, reading preferences, proposing and confirming preferences, and feedback. Set LLM_API_KEY, LLM_MODEL and optionally LLM_BASE_URL to opt in. Configured providers receive the query and tool results including profile information. Use only with an approved provider and user consent. No key is required for local embeddings or deterministic chat.

Four rounds and eight tool calls bound a turn. Generated calls pass schema validation before dispatch. Server-rendered structured results supply factual claims. A separate literal confirmation turn authorizes a pending preference. Feedback requires the dedicated control. Session state stores the query, constraints and last result IDs. Durable preferences are separate account-owned rows. The local parser recognizes the documented conversations and has limited free-form language coverage.

Hosted routing also requires request-level allow_provider consent. The router includes up to six recent user messages and active structured state. On a transport failure before any successful tools, the server runs the deterministic route and labels the fallback. Unverified model prose is discarded. Search, comparison and explanation summaries are rendered from the returned records.
