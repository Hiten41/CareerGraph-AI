# Deployment runbook
Compose provisions pgvector, waits for PostgreSQL health, runs Alembic and starts the API and web service on loopback. The database and model cache use named volumes. First startup requires registry and model-download access. Use the README commands, then verify /api/v1/health/ready, register, seed and run the browser walkthrough.

For cloud hosting, build infra/api.Dockerfile and infra/web.Dockerfile from the repository root. Configure the reachable internal API address at frontend build time. Provision managed PostgreSQL supporting pgvector, back up the database, run the migration once as a release job and point API replicas at the migrated database. Supply production credentials from a secret manager, configure HTTPS origin and Secure cookies, limit ingress and run authenticated smoke tests before routing traffic. Keep demo accounts and synthetic imports isolated from real inventory.

No cloud deployment was authorized. Docker was unavailable locally. Provider-backed LLM behavior, production concurrency, cloud rollback and container startup are unverified.
