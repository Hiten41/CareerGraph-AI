# Privacy boundaries
Passwords use Argon2. Only hashed bearer tokens are stored, with one-week expiry and a separate CSRF secret. Cookies use HttpOnly and SameSite=Lax. Set COOKIE_SECURE=true behind TLS. Account ownership predicates and role checks are enforced in the API. Account deletion cascades to historical conversations and preferences. The raw resume is discarded after local extraction. Only user-approved profile fields are saved.

The initial HTTP rate limiter is process-local. Before public exposure, use a reverse proxy enforcing streamed request size, shared rate limits and TLS, isolate PDF parsing under resource limits, define backup retention and perform a security review. External provider processing requires a provider agreement and a consent flow suited to the deployment.

Migration 0002 initializes every account with provider_consent=false. PUT /api/v1/privacy/provider-consent is session-owned and CSRF-protected. Chat requires both that persisted flag and an opt-in on the request. Hosted PDF parsing additionally requires the explicit hosted upload option. Revocation blocks future requests; it cannot retract material already transmitted. PDF extraction uses selectable text, quoted source lines and editable drafts. The hosted parser requests excerpts, accepts only original document lines, and derives fields locally. This path has no live provider verification.
